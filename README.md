# cool-stuff

- [`walled-city/`](walled-city/): **九龍城寨 · Kowloon Walled City**. A generative, real-time 3D model of the
  Walled City growing from 1945 huts to the 14-storey monolith capped by Kai Tak's flight path, with
  747s on short final, a first-person walk through the lanes, and the 1993–94 demolition.
  Open `walled-city/index.html` in a browser.
